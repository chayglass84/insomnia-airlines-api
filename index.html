Insomnia Airlines API

Running at http://localhost:8000 — Interactive docs: /docs  |  /redoc

Airports

MethodPathParamsDescription
GET /airports country (ISO 3166-1 alpha-2) limit (1–100, default 50) List all airports, optionally filtered by country
POST /airports body: Airport JSON Register a new airport
GET /airports/{iataCode} iataCode (path) Get a single airport by IATA code (e.g. YYZ)
PUT /airports/{iataCode} iataCode (path) body: Airport JSON Replace an airport's details
DELETE /airports/{iataCode} iataCode (path) Remove an airport (fails if active routes reference it)

Routes

MethodPathParamsDescription
GET /routes origin (IATA code) destination (IATA code) List published routes, optionally filtered by origin/destination
POST /routes body: RouteInput JSON Publish a new city-pair route
GET /routes/{routeId} routeId (path, UUID) Get a single route by ID
DELETE /routes/{routeId} routeId (path, UUID) Withdraw a route (fails if future flights reference it)

Flights

MethodPathParamsDescription
GET /flights origin destination departureDate (YYYY-MM-DD) status limit (1–200, default 50) List scheduled flights
POST /flights body: FlightInput JSON Schedule a new flight instance
GET /flights/{flightNumber} flightNumber (path, e.g. IA204) departureDate (query, YYYY-MM-DD) Get a specific flight by number and date
PATCH /flights/{flightNumber} flightNumber (path) departureDate (query) body: FlightPatch JSON Update status, gate, or times
DELETE /flights/{flightNumber} flightNumber (path) departureDate (query) Cancel a flight (soft-delete, sets status to CANCELLED)

Flight statuses: SCHEDULED · BOARDING · DEPARTED · ARRIVED · DELAYED · CANCELLED
